Nolli — interface reference

A static recreation of the macOS app’s 11 main states, built from its real layout, sizes and colours (see tokens.css). Map imagery is a screenshot. Controls are plain HTML, so each can be selected and restyled. Icons are simplified stand-ins for the app’s SF Symbols.
